# MBC-Pro Sensors

Competition-grade, plug-and-play sensors for **LEGO® Education SPIKE™ Prime**, **MINDSTORMS® EV3**, **Pybricks** and **Arduino**, built for WRO and STEM robotics.

**Website:** [mbc-pro-sensors.github.io](https://mbc-pro-sensors.github.io/?utm_source=github&utm_medium=referral&utm_campaign=org_profile)

| Product | What it does |
| :--- | :--- |
| [Pathfinder 8-Way / 16-Way](https://mbc-pro-sensors.github.io/en/sensors/line8/) | 8/16-channel line followers with a line position output ready for PID |
| [Ranger 2-Way / 8-Way](https://mbc-pro-sensors.github.io/en/sensors/tof8/) | Class 1 ToF laser ranging, up to 180° in one read |
| [SPIKE 6-Way Expander (EXP6)](https://mbc-pro-sensors.github.io/en/sensors/exp6/) | One SPIKE Prime port to six, with its own motor power |
| [Controller PS4/PS5 and 2.4G](https://mbc-pro-sensors.github.io/en/sensors/ps4/) | Gamepad receivers for remote-control events |
| [Sharpshooter Vision (ESP32CAM)](https://mbc-pro-sensors.github.io/en/sensors/esp32cam/) | Color-tracking camera with an on-device setup screen |
